# mobile — App Flutter (PIM IV)

Aplicativo Flutter que consome a `PharmaStock.Api` (ASP.NET Core Web API).

## Escopo do manual

- Consumir endpoints REST da API
- Implementar ao menos uma funcionalidade complementar ao sistema web
- Telas responsivas / adaptadas a dispositivos móveis

## Criar o projeto

```bash
flutter create pharmastock_app
cd pharmastock_app
flutter pub get
```
